## 个人作品集网站初始化搭建

### 背景
基于赵鹏的个人简历（`C:\Users\MR\Desktop\个人简历.docx`）从零搭建个人作品集网站。

### 技术栈
- React 18 + Vite
- Tailwind CSS 3（暗色主题 + 自定义配色）

- React Icons（图标）

### 已完成模块
1. **Hero 全屏首页** — 粒子动画背景、大标题"赵鹏"、导航栏锚点链接、联系按钮
2. **About 个人经历** — 头像占位区、个人介绍、联系方式、6个关键数据卡片（100万+字、3万+流水等）、7条时间线
3. **Projects 精选项目** — 4个大卡片：凤雏数字新生（跨2列）、三星堆实践、漫画翻译、日语IP
4. **Strengths 核心优势** — 6张卡片：执行力、领导力、多语言、商业敏感度、新媒体运营、跨领域整合
5. **Contact 底部收尾** — 全屏粒子背景、4个联系方式卡片、回顶按钮、版权信息

### 设计风格
- 暗色系（#080a0c ~ #0d0f12）
- Accent 色：Indigo/Violet (#6366f1)
- 版心：max-w-[1700px]
- 玻璃卡片效果（glass-card）
- 底纹粒子动画（Canvas）
- 渐变文字（text-gradient）
