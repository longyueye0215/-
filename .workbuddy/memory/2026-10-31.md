## 六边形加载效果拆解与复刻

- 需求：拆解参考站（sci-fi HUD「棋盘室 / RECORDS」）的六边形加载效果，并给出适配提示词。
- 拆解结论（3.11s 录屏，1386×640，24fps）：分层 L0 暗场渐晕 / L1 二进制 0/1 底纹 / L2 平顶六边形蜂窝网格（单格≈170px，1px 冷白描边，边缘亮中心暗，少量格子呼吸高亮）/ L3 中央光圈加载器（白盘+4 裂缝+暗齿轮+虚线刻度环）+ 大写字品牌 glitch + 正弦波 + `[LOADING] → ACCESS SYSTEM` 状态行；结束时网格按「距中心距离」错峰逐格溶解，露出真实页面。

## 工程落地：HexLoader 组件（React，总时长 1s）

- 新增 `portfolio/src/components/HexLoader.jsx` + `HexLoader.css`：Canvas 画平顶六边形网格 + inline SVG 光圈 + rAF 单时钟时间轴；props `brand/duration/hexSize/accent/onDone`；支持 `?t=毫秒` 冻结单帧用于逐帧录制、Esc/点击跳过、`prefers-reduced-motion` 直接跳过。
- 已接入 `App.jsx`：`{booting && <HexLoader brand="LONGYUEYE—ARCHIVE" duration={1000} onDone={...}/>}`，首屏播一次。
- 1s 时间轴比例常量（×duration）：IN_END 0.14 网格淡入 / CORE_IN 0.10 加载器出现 / PROG 0.12→0.58 进度 / OUT_START 0.58 起逐格溶解。
- 踩过的坑（重要）：
  1. `.hl-root` 不能有实底 background，底色必须由 `.hl-veil` 提供，否则溶解阶段露不出下层页面。
  2. Canvas 尺寸一旦被 resize 重置就等于清空，必须 `onResize → build() → renderFrame()` 补画（冻结单帧时尤其明显）。
  3. 呼吸高亮格子的透明度要在 `×(1-k)` 之前叠加，否则溶解后永远残留几个亮点。
  4. 视口尺寸用 `.hl-root` 的 `getBoundingClientRect()` 取，别用 `window.innerHeight`（滚动条/100vh 会差几十像素）。
- 验收产物（`hex-loader/`）：`hex-loader-1s.mp4`（1440×900 / 25fps / 1.04s）、`hex-loader-1s-slow.mp4`（0.5× 慢放）、`timeline-contact.jpg`（每 120ms 一帧的联系表）。
- 录制方式：`vite build --config vite.preview.config.js` → 静态托管 `dist-preview/previews/hexloader.html` → Edge 无头 `--screenshot` 按 `?t=` 逐帧截图 → ffmpeg 合成（本机 Edge 只监听 [::1]，需 `--no-proxy-server`；vite dev 也只在 [::1] 监听）。
