# 六边形加载效果 · 复刻提示词（适配本仓库技术栈）

> 用法：整段粘贴给编码型 AI（或交给我执行）。已按 `个人站/portfolio` 的现状写好——
> React 19 + Vite + Tailwind 3 + GSAP，**不新增任何依赖**，落点复用现有暗色体系
> （`dark-950 #080a0c` / `accent #6366f1`）。

---

## 一、可直接粘贴的提示词（完整版）

```
【任务】
在我的 React + Vite + Tailwind + GSAP 项目里，新增一个「六边形蜂窝加载页」组件，
复刻 sci-fi HUD 网站常见的 hex-grid loader：暗场 + 二进制底纹 + 六边形网格 +
中央光圈加载器，加载完成后六边形格子从中心向外逐格溶解，露出下方真实页面。

【技术约束】
- React 19 函数组件，Vite 已配置，Tailwind 3 已配置，GSAP 已在依赖里。
- 禁止新增 npm 依赖；禁止引入图片资源；六边形与光圈全部用 Canvas / 内联 SVG 绘制。
- 颜色只用主题色：背景 #080a0c（dark-950）、强调色 #6366f1（accent-500）、
  浅色文字 #e6eaf2，网格线 rgba(196,210,255,α)。
- 所有尺寸用 CSS 变量集中管理，方便后续调参。

【文件结构】
- src/components/HexLoader.jsx      —— 组件本体
- src/components/HexLoader.css      —— 该组件的样式（不污染 index.css）
- src/App.jsx                       —— 首屏挂载一次：<HexLoader brand="LONGYUEYE—ARCHIVE" />

【视觉分层（从下往上，z-index 依次递增）】
L0 暗场底：全屏 #080a0c，叠一层 radial-gradient(90% 70% at 50% 45%,
   #0c0e16 0%, #07080b 60%, #05060a 100%)，做出「中心微亮、四周更黑」的纵深。
L1 二进制底纹：用等宽字体（JetBrains Mono）铺 40~50 列 "0/1" 字符，
   列间距 26px、字号 12px、行高 1.6、颜色 #1e2536、整体 opacity .55；
   每列随机 animation-delay 做 4~5s 的 steps 闪烁（0.55 → 0.2 → 0.62）。
   注意：不要让它抢戏，正常观看几乎看不出是数字，只留一点「数据流动」的噪点感。
L2 六边形网格（Canvas）：平顶六边形（上下边水平、左右为尖角），
   外接圆半径 R = 86px（单格宽 172px，1440 宽约 8 格多）。
   中心坐标：x = col * 1.5R，y = row * √3R + (col 为奇数 ? √3R/2 : 0)。
   描边 1px；每格透明度 = 全局 alpha × (0.13 + 0.24 × (1 - 距中心归一化距离))，
   即边缘略亮、中心更暗；再随机抽 5% 的格子做 700ms 周期的呼吸高亮（+0.11，偏 accent 色）。
   整层套一个 radial mask，让四角自然收边。
L3 中央加载器（内联 SVG，124×124，flex 竖排 gap 15px，整体水平垂直居中）：
   ① 光圈主体：白色圆盘 r=33（#f4f6fb），叠 4 条 3px 的深色裂缝
      （在 38°/128°/218°/308° 方向，从 r=33 向内切到 r=16），
      中心压一个 #14161c 的暗齿轮 r=13 + 8 颗 #2b2f3a 小齿 + 1 个 r=5.2 的 accent 描边圆。
      整组 9s 匀速顺时针旋转；外层再套一圈虚线刻度环（stroke-dasharray 2 7，26s 反向转）。
      SVG 加 drop-shadow(0 0 14px rgba(160,180,255,.28)) 做冷光晕。
   ② 品牌字：等宽 11px、letter-spacing .38em、全大写、色 #e6eaf2，
      用 ::before/::after 复制两份做 RGB 错位 glitch（青 #22d3ee / 品红 #f472b6，
      各 1~2px 偏移 + clip-path 上下切条，3.4s/3.9s steps 动画，92% 时间里完全不可见）。
   ③ 正弦波：190×22 的 SVG path，用 rAF 每帧重算 d 属性，
      y = 11 + sin(x/12 + phase) × amp，amp 再做一次低频调制（5~8px 之间呼吸）。
   ④ 状态行：`[ LOADING ]` + 118px 的 1px 进度槽（accent 渐变填充）+
      两位数字百分比 + `→ ACCESS SYSTEM` + 闪烁方块光标；字号 9.5px、字距 .16em。

【时间轴（总长约 3.4s，用单个 rAF 时钟 + applyState(elapsed) 驱动，不用一堆 setTimeout）】
0 → 420ms      ：L2 网格整体 alpha 0 → 0.92（easeOutCubic），L0/L1 就位。
231 → 2381ms   ：L3 加载器 280ms 淡入；进度 0 → 100% 走 2150ms；波形持续呼吸。
2381 → 3200ms  ：L0/L1 在 280ms 内快速淡出（先擦掉底噪，保证内容对比度）；
                 L3 在 450ms 内淡出；L2 每格按 `距中心距离 × 0.55 + 随机 × 0.25`
                 错峰溶解（单格过渡 0.35），形成「从中心向外逐格消失、网格先碎再散」的观感。
3200ms 之后    ：卸载组件（或 opacity 0 + pointer-events none），页面可交互。

【交互与健壮性】
- 加载进度是「视觉进度」，真实数据就绪时提前结束：暴露 onDone 回调与 progress prop，
  进度至少走完 65% 再允许跳结束，避免闪一下就没了。
- 支持点击任意处 / 按 Esc 立即跳过（直接进结束态）。
- prefers-reduced-motion: reduce 时完全不加载该动画，直接渲染页面。
- 移动端：R 降到 56px，二进制底纹列数降到 18，加载器缩到 96px。
- 性能：Canvas 按 devicePixelRatio（上限 2）适配，单帧只 draw 一次；
  不要给几百个 DOM 节点加 box-shadow 或 filter 动画；网格用一条 Canvas 而非 N 个 div。

【交付要求】
- 组件 props：brand、duration、hexSize、accent、onDone、progress。
- 给出 App.jsx 中的挂载示例，并说明如何与现有 WarpTransition 衔接
  （默认：首屏进站播一次；路由/锚点切换不重复播放）。
- 附一段 5 行的简短注释说明每个变量的作用，方便我后续自己调「网格密度 / 溶解速度 / 光晕强度」。
```

## 二、精简版提示词（想一句话丢给 AI 时用）

```
做一个全屏 sci-fi 六边形加载页：暗场 #080a0c + 极淡的 0/1 二进制底纹 +
平顶六边形蜂窝网格（单格约 170px、1px 冷白描边、边缘比中心略亮、5% 格子呼吸高亮）；
屏幕正中一个白色光圈插件（四道深色裂缝 + 暗色齿轮轴心，9s 匀速旋转，外层虚线刻度环反向转），
下方依次是等宽大写字品牌名（带青/品红 RGB 错位 glitch）、一条正弦波、`[ LOADING ] ▬▬ 42 → ACCESS SYSTEM` 状态行；
加载完成后网格按「距中心越远越晚消失」逐格溶解，露出下面的真实页面。
用 React + Tailwind + 原生 Canvas/SVG 实现，不引新依赖，总时长 3.4s，支持 reduced-motion 与点击跳过。
```

## 三、原站效果拆解备忘（做参数对照用）

| 层 | 元素 | 关键参数 | 作用 |
|---|---|---|---|
| L0 | 暗场 / 紫黑渐晕 | `#0a0714` 级底色，中心微亮 | 建立纵深，压住内容 |
| L1 | 二进制 0/1 底纹 | 12px 等宽、低对比、随机闪 | 数据感噪点 |
| L2 | 六边形网格 | 平顶、约 170px/格、1px 冷白描边、边缘亮中心暗 | **承载体**：既是背景也是转场遮罩 |
| L3 | 光圈加载器 | 白盘 + 4 裂缝 + 暗齿轮 + 虚线刻度环 | 唯一高对比焦点 |
| L3 | 品牌字 | 大写字距 + RGB 错位 + 偶发 glitch | 强化「系统」语感 |
| L3 | 正弦波 / 状态行 | 1px 线、9~10px 字、进度槽 | 让「加载」这件事可被阅读 |
| 转场 | 逐格溶解 | 按距中心距离错峰 | 网格先碎再散 → 内容浮现 |
